# Review identity

This is the private, anonymous review distribution of the PertRank reproduction package, version **1.5.4**. No public release is implied by this archive or by its repository-ready layout.

Project-owned OSF registration and project identifiers are represented by the following role aliases:

| Alias | Record role |
|---|---|
| `REST_PRIMARY_REGISTRATION` | Original registration for the fixed Rest task |
| `REST_ASSOCIATED_PROJECT` | Project associated with that registration |
| `STIM_PRIMARY_REGISTRATION` | Original registration for the Stim task |
| `STIM_ASSOCIATED_PROJECT` | Project associated with that registration |
| `ADDITIONAL_PRIVATE_REGISTRATION` | Additional private registration retained in the execution record |

These aliases are labels, not URLs or newly created registrations. They do not assert that an anonymous access link has been issued. Original record identifiers and the unmodified source documents are retained separately for confidential editorial verification; they are not included in this reviewer archive. Registration dates, protocol content, analysis status and scientific outcomes retain their original meanings. A registration alias appearing inside a historical path identifies the same archived source record; it is not a runnable local path.

Only confirmed project-owned identifying text has been replaced. Scientific arrays, numeric results and analysis definitions are unchanged. Public dataset identifiers, third-party paper citations, upstream repositories, copyright notices and licenses are retained so that attribution and software provenance remain verifiable.

The code availability statement for this release is supplied in `CODE_AVAILABILITY.txt`. The manuscript files themselves are not part of this code-package maintenance update. Reproduction coverage and the starting intermediate for each module are documented in `REPRODUCTION_SCOPE.md` and `PAPER_COVERAGE.csv`.
