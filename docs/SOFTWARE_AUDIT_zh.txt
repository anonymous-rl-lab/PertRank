PertRank 软件审计与升级报告

交付身份：软件 0.2.0rc2；总代码包 v1.5.3；对齐论文 v25.2。

一、实际修复
1. 外部估计器复用结果不再将外部效应与原始能量/噪声混成同一套统计量。
2. 连续复用保留原始基因轴，可继续查询原输入中保存的其他基因。
3. 结果间不共享可变统计数组，避免新结果的修改污染原结果。
4. 补齐整数 counts、参数类型、有限分数、身份对齐及存档基因轴校验。
5. 总包启动器保留虚拟环境解释器路径；软件入口先核对实际安装的源码与数据。

二、功能提升
新增 evaluate_reference：在固定候选池、查询与 K 下，按身份排除查询基因自身，
以精确并列期望计算逐方法/查询/方向的 P@K 和参考成员期望数。
外部估计器复用后的 Unweighted 表示该外部估计器未加权，避免与原始均值效应混淆。
README、API、科学设计说明、中文说明和两份教程对齐当前论文主张。

三、实际验证
源码 99 项测试通过；最终安装 wheel 的 99 项测试通过，无失败或跳过。
Replogle 与 T 细胞教程的 9 个代码单元全部通过；合成 AnnData 快速示例通过。
两套真实数据夹具的权重最大绝对差异为 4.44e-16，冻结数值回归通过。
总代码包 software 入口通过安装身份、测试、教程及旧 AnnData 应用兼容性检查。
186 个数值载荷文件和 97 个论文 CSV 与 v1.5.2 逐字节一致。
未新增科学实验、拟合、原始数据下载或调参。

四、发布与验证范围
本次交付为匿名私有安装包，不是公开 PyPI 发布，不宣称已被 pertpy/scverse 接收。
公开 PyPI 的 pertrank 项目 JSON 接口在本次查询返回 404；现有交付来源是私有 rc1。
教程采用逐代码单元执行并捕获输出；本环境限制本地网络接口，交互式 Jupyter 传输未验证。
新增评分器实现既有评分定义，不自动建立参考独立性，也不自动计算跨来源推断或区间。
七个默认科学模块保留 v1.5.2 已完成验证记录；本次软件更新未重跑这些科学模块。
