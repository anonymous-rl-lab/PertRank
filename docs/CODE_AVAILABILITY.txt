Code availability

An anonymous reproducibility package is supplied with the review materials. It includes the PertRank software, analysis code, compact intermediate inputs, retained reference outputs, current manuscript source tables and figure scripts, dependency specifications, and a unified offline reproduction entry point. The default workflows include the independent-RNA four-arm comparison and guide diagnostics. An optional PertRank-Q workflow reconstructs predictions from retained model inputs and selected checkpoints and recomputes the original candidate-subpool statistics; it does not retrain models.

Reproduction starting points and unavailable upstream stages are specified in docs/CURRENT_PAPER_COVERAGE.md and docs/REPRODUCTION_SCOPE.md. This package does not claim that every analysis is regenerated from raw counts. Project-identifying public links and author metadata are omitted for anonymous review. Third-party licenses and independent dataset accession identifiers retain their original scope. No public repository, DOI, PyPI release or live Code Ocean capsule is created by this delivery.
