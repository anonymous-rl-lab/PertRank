Code availability

The anonymous PertRank reproduction package, version 1.5.4, is supplied with the review materials. It includes the analysis code, compact intermediate data, retained reference outputs, figure and table source data, dependency specifications, and a unified reproduction entry point. The default reproduction chain operates from the documented intermediates for each module, including saved effects, query-level scores and sufficient statistics. Coverage and archived-only items are identified in docs/REPRODUCTION_SCOPE.md and docs/PAPER_COVERAGE.csv. This distribution does not claim that every analysis is regenerated from raw sequencing counts. Project-owned registration identifiers are represented by role aliases; the confidential mapping to the original records is retained separately for editorial verification. Third-party source attribution and licenses are preserved.
