# PertRank 匿名审稿总包：审计与修订结果

本包已同时检查主方法、PertRank-Q、当前论文新增证据、软件文档和统一复现入口。交付对象为匿名审稿代码数据包，不包含论文历史版本，也没有向公开仓库或 PyPI 上传。

## 已修正的问题

| 问题 | 处理 |
|---|---|
| 三个文档存在，但从 PyPI 项目页点击相对路径会形成错误地址 | 总包首页及软件 README 使用匿名 GitHub 仓库的三个 HTTPS 文档链接；生成的 PyPI 描述保留这些链接，并将其余本地链接转换为明确的源码归档路径 |
| 新论文独立 RNA 四臂和 guide 诊断未进入原统一总包 | 加入 `current_paper` 默认工作流，复用核心输入，重新计算四臂、诊断和固定名单得失 |
| 当前图表与旧展示副本并存 | 保留当前111份数值表格和6张主图、7张补图的代码；移除过时展示副本 |

| 项目身份或工作路径可能影响双匿名 | 清除项目作者、联系信息、可识别作者身份的项目链接和私人目录；保留用户确认的匿名仓库文档链接、外部数据来源、第三方许可及算法依赖版本 |
| 匿名化改变了文档和来源记录的物理哈希 | 同步当前副本的活动校验值；所有数值核验保持原容差，没有放宽或跳过数值比较 |
| 重复存储及体积问题 | 合并99份重复拟合/运行报告，14个NPZ使用无损LZMA容器；232个数组的dtype、shape和完整内部NPY字节一致 |

## 复现口径与保留边界

默认八个科学工作流，加入Q后为九个。各模块从所声明的中间量、固定预测或检查点开始；不把分数重算、表图重绘说成原始细胞预处理或模型重新训练。软件测试另行运行，不计为新增生物学验证。

A14原始逐细胞输入不可用，原A19细胞选择未恢复，A19-R和CELLEQ-R的重建身份继续明确。缺口与原有阴性结果没有因清理而删除。第三方许可和独立数据集标识保留；软件现有许可没有被擅自改成开源许可。

本包清理了文件内的直接身份信息；上传时仍需使用期刊匿名审稿入口，避免附带具名账户页面或旧仓库Git历史。本次未进行任何远程发布。
