Plot source data for the six v21 main figures. All inputs are previously saved numerical summaries. No model fitting, scoring, resampling or scientific test is run by these scripts. figure_values.json retains exact source precision; manuscript-only legacy values retain their published precision. Intervals are conditional query-block intervals, not donor-population intervals. Independent RNA has one shared arrayed KO reference across three input sources.
Sources: v20 Supplement SN3.1/SN3.2, SN11.1/SN11.4, SN15/SN16/SN17; v1.4.0 benchmark_validation method_scores.csv; v1.3.0 interactions/RESULTS.json and native_rna/original_scores/*/report.json. Plotting commands: python figure_code/draw_main_figures.py from the paper package.
