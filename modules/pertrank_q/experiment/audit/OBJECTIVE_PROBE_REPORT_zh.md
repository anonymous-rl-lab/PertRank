# B 训练目标的只读归因探针

本轮读取18个既有训练池（12个内部训练池、6个外层校准池）、36个已有B拟合，以及相应校准曲线。没有新训练，没有按新留出成绩选择公式、温度或模型。内部验证成绩来自原先已经保存的曲线。

上述训练池、种子和分数条件嵌套于同三个输入来源，并非18个或54个独立实验；本报告的比例和均值均为机制诊断的描述性汇总。

## 1. 首要可修复问题：软名单目标奖励某些完全不改名单的尺度变化

原B使用冻结的训练标准差缩放分数，再以固定温度0.5计算SoftTopK。精确Top-K对所有候选分数的共同正比例变化不敏感，SoftTopK则会因分布变尖而改变。因此，软目标的一部分进步可以没有相应的名单进步。这是可微代理目标的性质，不是P@10实现错误。

| 只读诊断 | 内层训练池 | 外层校准池 |
|---|---:|---:|
| 检查的基线/已拟合分数条件 | 36 | 18 |
| 全部分数×2后精确P保持不变 | 36/36 | 18/18 |
| 全部分数×2后软重叠增加 | 36/36 | 18/18 |
| 平均软重叠增加 | +0.006370 | +0.005610 |
| 梯度平方量中每查询尺度方向比例 | 1.32% | 0.619% |

进一步把已有B修正投影到每查询的正仿射变化（共同平移及正比例缩放）上，获得：

| 已拟合B的分解 | 内层训练 | 外层校准 |
|---|---:|---:|
| 修正能量中可由仿射部分解释的均值 | 17.5% | 15.1% |
| 仿射部分造成的精确名单变化 | 0个拟合 | 0个拟合 |
| 仿射部分的平均软重叠收益 | +0.001069 | +0.000410 |
| B完整修正的平均软重叠收益 | +0.018992 | +0.005915 |

前两项软收益的比值分别为0.001069/0.018992≈5.63%、0.000410/0.005915≈6.94%。**这个可识别的尺度方向只解释约5–7%的平均软收益，不能把全部泛化失败归因于它。** 非线性名单任务中的这项投影也不是因果归因；数字用于定位代理目标中不服务于排名的一部分。

## 2. 一个受控更新建议

保留原几何锚点、B网络、竞争特征、bootstrap参考标签、温度0.5和原分数残差惩罚。只将SoftTopK的输入改为：对当前预测分数按查询，在全部合资格候选内减均值并除以当前标准差；标准差参与反传，底限使用1e−6倍原训练基线SD。精确P@10仍使用未经此训练归一化改写的最终物理分数。

这样使训练代理目标也对正比例尺度变换不敏感，迫使优化更多依赖候选之间相对次序。它仍是平滑代理，不等于直接优化离散P@10，也不保证迁移收益。

在上述54个实际条件中，新的归一化目标对0.5、1、2倍尺度的数值差全为0；梯度与共同尺度方向的内积绝对值最大约1.74×10^−18。实现需在平方根前设置方差底限，避免全零/常量查询的sqrt导数引出NaN；该退化情形的前向/反向检查已加入 `scale_probe.py`。底限活跃时近零分数不保证严格尺度不变，实际54个条件均通过所测尺度检查。

## 3. 参考标签不同，但现有证据提示它不是优先断点

B训练用三个外部RNA重复的经验donor-bootstrap Top-K成员支持度；选epoch和最终精确P使用三个重复均值的Top-K成员。这两种统计对象不同，代码中均明确实现，没有把经验支持度当成潜在真值概率。

| 标签诊断 | 内层 | 外层 |
|---|---:|---:|
| 支持度相对名义硬Top-K的平均质量移动 | 17.98% | 17.49% |
| 对支持度本身取Top-K时，相对名义名单的成员变化 | 0.955% | 0.859% |
| 已拟合参数梯度：支持度标签 vs 名义硬标签余弦 | 0.976 | 0.994 |

标签确有不同，但两个训练方向高度一致；不宜同时更换标签并宣称解决主断点。建议本轮保留标签，用单独的目标归一化改动建立可解释对照。

## 4. 温度和候选池大小的影响应记录，但不同时调参

固定温度0.5时，软成员质量相对精确名单的移动在内层平均36.4%、外层39.3%；SoftTopK曲率落在原始排名K±2带的比例分别为40.8%、19.5%。后一个差异部分来自内层K=5、外层K=10和候选数改变，不能单独解释为参数错误。

作为机制探针，温度降低到0.25或0.1会使软成员更接近硬名单，曲率更集中在边界；本轮没有据此选择新温度或训练模型。所有温度的完整结果保留在JSON。与此同时，96个原内部曲线的软目标改善步中，有49个验证P下降，7个训练精确P也下降。这说明代理目标与泛化名单质量之间仍有差距，但不能从这些汇总数字断定唯一原因。

## 文件

- `objective_probe.py` / `objective_probe.json`：全部训练池标签、梯度、温度和原曲线检查。
- `scale_probe.py` / `scale_probe.json`：共同尺度干预、已拟合仿射分解、新归一化不变性及退化方差检查。

**建议仅把“当前预测尺度归一化”作为本次优先受控更新。** 新训练完成前，只能说它消除了代理目标的一条排名无关方向，不能预告外部RNA P@10一定上升。
