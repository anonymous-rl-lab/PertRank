# PertRank B：归因、两轮受控更新与完整复现

**本轮获得一个小幅净正向的开发候选，尚未取得稳定突破。** 两阶段各自的主臂均未通过；预设次要臂 `B_rank_scale_free_pair` 的三来源平均P@10为0.395991，相对原PertRank增加0.001748，相对原B增加0.000281。所有失败结果保留，未按来源拼接最好模型。

## 实际完成的闭环

1. 回溯训练目标、训练/验证落差、模型选择与部署对象。
2. 按探针设计固定2×2：目标尺度与轮次选择两个因素。
3. 完成48次内层拟合（24次原B重放精确一致），以及23个唯一外层拟合。
4. 第一阶段后发现共同轮次附加了不必要的相同epoch限制，另立独立第二阶段协议；复用全部内层检查点，固定枚举25个轮次对，新增8个缺失外层拟合，其余复用。
5. 两阶段分别在六池预测全部锁定后统一评分；冻结权重重建、精确评分和名单换人逐项复算通过。

## 归因：已经排查并能复核的四点

**目标的一部分改善不改变名单。** 54个校准条件中，将全部分数乘2，精确名单不变而旧SoftTopK目标改善。正仿射分量仅解释已有B平均软收益约5–7%，不能解释全部失败。当前预测标准差参与反传后，这条尺度方向被消除；但单独修改尺度并未带来整体领先。

**训练进步不能替代靶点迁移。** 原B的24个内部训练损失均下降、训练精度均上升，最终训练平均增量约0.01658，验证平均仅0.000416，8/24验证为负。标签差异的梯度方向高度接近，未被本轮选为额外修改因素。

**应按最终使用的集成评分，但同轮次是额外限制。** 第一阶段共同选择只允许(0,0)、(50,50)等5个对角组合。第二阶段允许同一组固定轮次的25个配对，D3新收益主要出现在held1的(0,100)组合：原法锚点与训练模型平均后，完整名单相对原B增加0.003925 P@10；另一个半池反而退步。这是一个具体可复查的局部作用，不能概括成所有不同时刻组合均有效。

**新增信号已经落实到名单，但仍有抵消。** 对新候选与原B的完整名单比较：

| 来源 | 进入质量 | 进入支持 | 移出支持 | 净支持 | 净支持/(2×Q×10) |
|---|---:|---:|---:|---:|---:|
| D3 | 157 | 65 | 56 | 9 | 0.00153584 |
| D1 | 244 | 72.5 | 70 | 2.5 | 0.000432526 |
| D2 | 310.5 | 90 | 96.5 | -6.5 | -0.00112457 |

这些是双方向、所有查询汇总后再平均两个半池的分数成员质量，不是独立湿实验命中数。进入与移出总质量相等，净支持/(2×查询数×10)=精度增量，已逐池核验。当前增量之所以小，是D3/D1的新增支持被D2的支持损失部分抵消。

## 如何使用本轮结果

原B继续作为固定对照；新组合保留为探索性开发候选。不能将阶段2次要臂的阳性改写成主终点通过，也不能根据此表选择D3/D1用新模型、D2用旧模型来制造成绩。下一项需要检验的具体问题是：训练侧能否识别并减少跨靶点后发生的有害名单交换，同时保留当前有益交换。当前结果没有验证这一能力。

## 任务与统计范围

- D3/D1/D2分别建模，原几何权重仍为锚点；训练输入、原始效应方向、查询竞争特征与完整名单目标保持在B线路。
- 原始候选52/59/63；当前是整靶点两半留出，六池大小26/26、32/27、35/28，查询293/289/289，各池K=10。不跨折拼接候选分数。
- 本包约0.396的绝对精度对应这些留出半池，不能与原论文完整候选池约0.259的精度直接比较。
- 三来源共享一项外部RNA实验，历史参考已多次用于开发。预测锁定记录本次执行顺序，不使其变为新的盲确认。
- 所列区间为固定模型、候选与共享参考下的2000次配对查询块重抽样区间，不覆盖全部选择/训练/实验重做不确定性，未作多重比较校正。
- 第二阶段从5个对角组合扩展到25个组合，增加内部选择自由度，可能增加选择过拟合。全部300候选和选择规则已保存。

## 固定参考重复的敏感性检查

最终追加了无训练的事后检查：枚举两个外部参考批次各三个重复的全部100种经验重采样计数组合。相同批次的计数在三个来源、两个半池共用，批次之间独立重加权；所有9种方法均报告。

新次要候选相对原B的加权平均增量为 **+0.000396 P@10**，加权经验2.5%—97.5%范围为 **[-0.000434, +0.001178]**；正差异占重采样权重 **84.91%**。D3的对应经验范围为正，D1、D2仍不稳定。这个结果支持平均小正号并非只出现在名义均值参考上，但没有消除训练靶点迁移和来源异质性问题。

**该范围不是置信区间；84.91%不是方法成功概率或后验概率。** 这只是对现有三个参考重复的敏感性，未改变模型、主次身份或发展门。

完整结果在 `audit/reference_sensitivity/`。如需从紧凑包恢复派生预测并复算：

```bash
python audit/reference_sensitivity.py --rebuild --output-root check_reference
```

## 一键复算

测试环境为Python3.12、NumPy2.3.5、PyTorch2.15.0+cpu。依赖见baseline_B/requirements.txt。安装相应依赖后，在解压目录运行：

```bash
python replay_optimization.py --output-root check_stage1
python epoch_pair_update/replay_pair_update.py --output-root check_stage2
```

每条入口在临时目录重建旧B和新模型预测，再从同一参考复算全部数值；原结果不覆盖。已验证阶段1的2278个数值字段、阶段2的3091个字段和全部预测/评分数组精确复现。两个check目录应使用尚未存在的输出位置。
