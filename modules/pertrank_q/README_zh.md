# PertRank-Q 匿名审稿复现模块

本模块保存 PertRank-Q 的中间输入、冻结权重、训练代码、归一化参数、选择记录及直接比较结果。内部实验标识为 `B_rank_scale_free_pair`；两个阶段未通过的主臂与全部直接对照均保留。

## 运行

使用 Python 3.12、NumPy 2.3.5、PyTorch 2.15.0+cpu，安装方式见[英文说明](README.md)。在本模块目录运行：

```bash
python reproduce.py --output-dir ../q-replay
```

请指定包外的新目录。程序恢复无损中间数据和权重，重建六份对照预测，再实际复算两阶段成绩、配对区间、名单进出、100种参考重复重加权和300个原内层轮次组合。默认不训练、不调参、不改变已选模型；`passed` 表示复现计算通过，不表示所有实验成功标准均达到。

总代码包根目录入口：

```bash
python reproduce.py --only pertrank_q --output-dir ../q-results
python reproduce.py --with-q --output-dir ../all-results
```

## 结果

| 来源 | Q相对同池原PertRank的ΔP@10 | 条件95%区间 |
|---|---:|---|
| D3 | +0.002474 | [+0.000257, +0.004613] |
| D1 | +0.001125 | [−0.001302, +0.003725] |
| D2 | +0.001644 | [−0.000868, +0.004468] |
| 等来源均值 | +0.001748 | 描述性等权均值 |

等来源P@10为0.395991。评价对象是整靶点留出的六个候选子池，各池K=10；不能与完整候选池约0.259的精度混比。三个输入来源共用一项外部RNA参考，区间条件于已选开发模型。
