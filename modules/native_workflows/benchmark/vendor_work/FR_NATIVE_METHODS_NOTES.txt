Native FR-Perturb benchmark implementation notes

Source provenance
Official douglasyao/FR-Perturb repository, commit 24e653b6a5c050ab17f3600ebaf222bef32e2d25. The vendor source is unchanged and each fit verifies its file hashes. The wrapper limits native numerical threads to 2, captures solver diagnostics/timings, uses an in-place dense centering operation independently verified bitwise against the original allocation, and preserves native floating-point outputs before the CLI's three-significant-digit export. The original CLI and adapter were compared in the same recorded dependency environment; this is not a claim of identical behavior across software versions or hardware.

Inputs and preprocessing
Each fit receives the common shallow raw-count input: 20 cells per target and 2,000 NTC cells. The complete provided raw gene axis is supplied; genes with zero expression across the fit input are filtered by the official min_cells=1 procedure. Gene filtering does not inspect any deep reference. Counts are normalized to 10,000 per cell, log1p transformed, and centered on the supplied NTC-cell mean. The target one-hot design includes an explicit NTC column. All supplied shallow target and NTC cells participate in dictionary learning.

Native model
Official factorize_recover runs SPAMS dictionary learning with its fixed 50-iteration budget, followed by native sparse projection and sklearn Lasso recovery with fit_intercept=False, default tolerance 1e-4 and default maximum 1,000 iterations. Fixed dictionary iterations are reported as a budget, not as a demonstrated convergence result. Official LOWESS scale_effs is applied, preserving full precision; the fitted NTC row is excluded from target output without subtracting it a second time. Positive gene-wise scaling was verified to preserve every within-gene target order in each fit.

Development and transfer
The frozen 21-configuration search crosses ranks 5,10,20,40,50,75,100 with native Lasso alpha 1e-5,1e-4,1e-3; SPAMS alpha=0.1 is fixed. D3 native-FR P25 selects one winner according to the already frozen tie rule. The chosen rank100/alpha1e-4 configuration is transferred unchanged to primary D4 fits. A separately frozen sensitivity uses alpha_D3*(26000/20)/(N_task/20), preserving the one-hot effective penalty as the number of fitted cells changes. It does not replace primary results or enable D4 parameter selection. NumPy/Python seed is 20261012+input replicate; SPAMS exposes no seed parameter, so empirical repeated-process identity is recorded separately.

Numerical audit correction
Two high-alpha D3 configurations produced valid native approximate Lasso outputs that failed an additional wrapper coefficient-accuracy threshold. Independent reviewers verified their default dual-gap stopping criteria and exact convex objective differences. Before any FR performance scores were read, the extra coefficient threshold was replaced uniformly for all 21 configurations by native dual-gap and exact one-hot objective-gap criteria; coefficient differences remain disclosed diagnostics. No native tolerance, parameter, or coefficient was changed. The two configurations were rerun solely to complete output serialization and reproduced B/U/U_tilde/W bitwise. Both original failed wrapper reports and their arrays remain preserved. The effective grid and append-only audit amendment explicitly record this history.

Storage and reproduction
Full original effects and native factors were retained for initial evaluation. Compact exports preserve exact frozen-query effects, target/gene/cell axes, fixed weights, native U/W, scale factors, fit reports, source hashes and numerical certificates. Query serialization was verified bitwise, as was U@W reconstruction in the execution environment. Compact exports explicitly omit dense B and cell-latent U_tilde; source hashes do not imply those omitted arrays are embedded. Cross-platform BLAS reconstruction may have floating-point rounding differences, while stored query effects reproduce the original scoring inputs exactly.
