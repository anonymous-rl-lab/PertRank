# 两项新增实验成果与复现说明

本模块对应论文新增的两项工作：固定原生 rvalues 比较，以及预定义转录程序的候选提名。D3 的程序开发诊断、sci-Plex3 的冻结评价和后续方向调整分别保留其分析身份。

## 成果一：与直接面向选择的原生 rvalues 方法进行固定比较

保持既有候选池、输入、查询、方向、K、排除规则和评分器，完成 D4 两状态及三个外部 RNA 输入任务的补充比较。PertRank 相对所测试 rvalues 配置的结果如下；正数表示更高的参考名单重叠。

| 任务 | 指标 | PertRank − rvalues |
|---|---|---:|
| D4 Rest | P@25 | +0.089208 |
| D4 Stim | P@25 | +0.091364 |
| 外部 RNA D3 | P@10 | +0.009955 |
| 外部 RNA D1 | P@10 | +0.031938 |
| 外部 RNA D2 | P@10 | +0.036783 |

该实验增加了完整工作流的竞争证据。几何的独立增量仍由固定读出下的 PertRank − Euclidean 比较识别。它是固定的事后补充分析；三个外部输入共享同一个 RNA 参考实验。详细区间、原生拟合状态和所有比较均可重算，见 rvalues 输出。

## 成果二：预定义转录程序的药物候选提名

保留六个固定程序、三种细胞系、两个培养方向及全部六臂。六个程序分别为 IFN-γ response、TNFα signaling via NF-κB、IL2–STAT5 signaling、E2F targets、G2M checkpoint 和 oxidative phosphorylation。

sci-Plex3 中，原始 PertRank 相对程序级原生 ASH 的名单平均有向参考响应增加 **0.026955 个输入对照程序标准差**，97.5% 条件参考区间为 **[0.012721, 0.041110]**，达到既定应用判据。这里评价的是名单在另一培养测量中的响应价值，单位不同于 P@10。

固定 ASH 读出后，几何相对 Euclidean 的增量为 **−0.006227**，97.5% 条件参考区间为 **[−0.014139, 0.001785]**。ASH 几何迁移及原定联合判据均未通过；ASH×Euclidean 的效用点估计最高。完整六臂和三条未成功方向调整均保留。

这项结果支持程序与药物提名用途，并说明全谱可靠性信息的选择价值随读出和任务改变。全谱层面的可重复信号，不自动决定特定程序边界上的候选应如何换入、换出。条件区间描述固定输入、名单和已观测培养条件下的参考测量不确定性，不是培养总体或研究总体的推广区间。

## 紧凑包如何保留复现能力

- 保留程序定义、任务身份、固定配置、原生输出和计算入口。
- 对只通过均值、方差进入后续计算的输入细胞，存储按原计算顺序获得的精确统计量；这保留当前复现所需的信息，不宣称恢复原始逐细胞输入。
- 保留参考重采样需要的逐细胞投影；不减少重采样次数，不降低浮点精度。
- 相同数组只保存一次，并使用可逆压缩；评分、名单、配对差值、区间和替换分解重新计算，再与原结果校验。
- 期望结果与数组指纹仅作为核对目标，不替代实际计算。

运行 `python run.py all --out /新的输出目录` 可计算核心结果与探索诊断；`core` 和 `exploratory` 可分开运行。输出的 `REPLAY_SUMMARY.json` 汇总各项核验。依赖见 requirements.txt。

轻量包不重新拟合原生 R 模型，也不从测序计数重建输入。完整 rvalues 效应/标准误及 Python/R 原生拟合材料在代码总包的 `modules/rvalues_native/` 中保留。PertRank-Q 继续使用总包原有独立入口，与本次两项新增实验分开。
