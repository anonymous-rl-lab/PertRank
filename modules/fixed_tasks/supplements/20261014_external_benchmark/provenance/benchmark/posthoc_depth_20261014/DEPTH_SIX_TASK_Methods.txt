Post-hoc input-depth diagnostic

We evaluated a post-hoc depth diagnostic on 250 D3 Rest perturbation candidates selected using the frozen metadata-based rule, with a fixed 300-query panel, reference and 2,000 input controls. The 20-, 50- and 100-cell inputs formed a single nested chain for each candidate. Raw-effect estimates and the Euclidean and PertRank weights were recomputed from the corresponding input depth and controls; weights were not estimated from FR-Perturb outputs. We applied native FR-Perturb with a fixed rank of 100, sparse-PCA penalty of 0.1, 50 dictionary iterations and random seed 20261012. The primary diagnostic curve retained the native default Lasso penalty of 0.0001 at every depth. A separately labelled sensitivity curve used alpha(n) = 0.13n/(250n + 2000), without substituting that curve for the default-penalty results. Neither rank nor other hyperparameters were selected separately at each depth.

We scored raw, Euclidean-weighted and PertRank-weighted effects, together with native FR-Perturb and its Euclidean- and PertRank-weighted variants, using the unchanged scoring implementation. The identity and order of cells, candidate targets, genes, queries and query blocks, together with the frozen reference, were checked before scoring. Source, protocol, input and native-output hashes were verified. An independent implementation reproduced query scores, sampled query blocks, bootstrap results and contrasts for both P@25 and P@10. Native and scoring execution owners had to finish before a separate integrity check released their outputs. Common raw/Euclidean/PertRank arrays and scores were identical across the two penalty curves at each input depth.

All query-block bootstrap intervals from this diagnostic are descriptive and conditional on the selected candidate and query panels. Nested depths are dependent observations and do not provide independent input or donor replication. Absolute P@K levels from the 250-candidate task are not directly comparable with those from the 1,200-candidate primary task. The diagnostic reports signed contrasts at every depth, including any loss relative to raw ranking, and makes no confirmatory multiplicity claim.
