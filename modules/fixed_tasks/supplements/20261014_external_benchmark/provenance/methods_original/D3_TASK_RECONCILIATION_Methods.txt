For native external-method development, we used input repetition 0 of the previously defined D3 Rest pooled-guide task (the first 20 cells within each target's reserved 100-cell input block; deterministic target-cell positions 100–119). The main five-input analysis used all five mutually disjoint 20-cell groups from that same block. Both analyses retained the same 1,200 candidates, 300 responsive queries and 30 query blocks, 2,000 input non-targeting controls, 13,390-gene weighting axis, control-derived directions, and 100-cell-per-target deep reference. For unweighted, Euclidean and PertRank scoring, the original log normalization scale (8,261.5 counts), historical control center and fixed weighting parameters were retained. We excluded each query's own target and used the same exact boundary-tie expectation for positive and negative top-25 reference overlap. Replaying all five archived input groups gave P@25 values of 0.2830717051, 0.2817688343, 0.3130988566 for unweighted, Euclidean and PertRank ranking, respectively; restricting to input repetition 0 gave 0.2771427778, 0.2762491901, 0.3051450054. Thus, the 0.31310 versus 0.30515 PertRank values reflect five-input averaging versus a single development input, rather than a change in candidate pool, query panel or reference. Native FR retained its official method-specific preprocessing; the equivalence stated here concerns the shared task and the three scalar arms, not identical preprocessing across methods.
