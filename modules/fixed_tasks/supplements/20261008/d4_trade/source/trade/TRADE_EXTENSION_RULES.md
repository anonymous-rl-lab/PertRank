# Five-real-input TRADE-core completion, v17

This is a development extension on already-opened D3_Rest/D1_Rest/D2_Rest. It adds R20 repetitions 1–4 at positions 120–199 to the frozen repetition 0 at positions 100–119, with all candidates and all frozen weight genes. It is not new independent confirmation. No D4, Stim, HEK293T, panel change, gene sampling or target selection is permitted.

Use the identical official TRADEtools fit_ash core at commit 3432d108c43325e9df65276563d65144a26b69ce, R 4.4.3, ashr 2.2.63, halfuniform/uniform prior, n_sample=0, unchanged adaptive grid. Input effect and SE are original normalized mean differences and sqrt(target sample variance/20 + control sample variance/nC). The latent mixture gives S=TI+mu², nu=mean(SE²), w=S/(S+nu). Predictions remain w*y in the original gene coordinates. No gene-level posterior prediction is added.

All 3527 targets × 5 inputs = 17635 fits must be complete before new nomination performance is scored. Repetition 0's 3527 locked fits are reused after source hashes, moment/control input hashes, target/gene identities, moment-to-weight identities and source ledger checks. The 400 pre-existing unscored D3 fits in repetitions 1–4 may be reused only after exact TSV input SHA256 regeneration and output/source hash checks. Every resumed new batch must satisfy the same identity checks. A failed fit or mismatch blocks the arm rather than dropping a target.

Six R jobs, one BLAS/OpenMP thread each, donors processed sequentially. TSV inputs are temporary and removed only after successful validation; all fitted mixture parameters, summaries, input hashes and provenance remain. Successful checkpoints are atomic and restartable. The fit runner is frozen before new fitting; the unified scorer is frozen separately before any new performance scoring. No new performance is used for input validation or timing smoke.

Score all five matched arms (raw, Euclidean, fixed diagonal, PertRank, TRADE scalar) on the same five real inputs. Retain corrected own-target exclusion and exact tie-expectation P@25. Responsive panel is the primary development comparison and tercile secondary. Average both signed directions and all five input repetitions within each query, then use the existing 30 query blocks, 2000 paired bootstrap draws, seed 2026, two-sided 95% percentile intervals. Report each repetition and donor. Equal-donor mean may be a point summary, not a synthetic joint CI. These intervals remain conditional on fixed controls, reference, panels and candidate pools.

For PertRank minus each competitor: lower CI>0 superiority; upper CI<0 inferiority; otherwise unresolved. Separately, full 95% CI within [-0.005,+0.005] meets the predeclared practical equivalence tolerance. Labels may coexist. No D4 confirmation label is attached. New competitor selection is deferred until all eligible Pearson common-output arms are complete under the master protocol.

This extension does not overwrite v16 or reinterpret its single-block result. Five-block data replace neither the original frozen confirmations nor the remaining control-set uncertainty. All performance, including unfavorable or unresolved results, will be reported.
