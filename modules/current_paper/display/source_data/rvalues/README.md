# Native rvalues fixed comparison

`summary.json` gives all five task results and the equal-state D4 and
 equal-source external means; `method_scores.csv` and `paired_contrasts.csv`
provide complete comparisons. `primary_contrasts.csv` extracts PertRank versus
rvalues. These are fixed post hoc comparisons on previously analyzed data.

Positive precision differences favor the first method. The uncertainty is the
original paired query-block bootstrap, conditional on measurements; it is
unrelated to the program reference-list stability ranges. External equal-source
means share one independent RNA reference, and no independent-source population
CI is supplied. Whole-workflow contrasts do not isolate geometry.
