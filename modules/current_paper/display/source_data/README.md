# Source data for PertRank current submission

These files contain the numeric inputs used to display the existing results and the completed additional analyses. They do not introduce new fits, new query selection or new inferential analyses.

- `figures/`: numeric data retained from the original method, controlled design comparisons, D4 comparisons, mechanisms, input efficiency and panel transfer. Superseded display variants and old layout manifests have been omitted.
- `si/`: detailed native-method, independent-RNA and paired-interaction source tables used by the retained supplementary analyses.
- `application/`: the previously fixed CTLA4 worked example, including all candidates, all five input groups, full top-25 lists, changed candidates and provenance. Its reference is the same-screen deep RNA reference, not the independent knockout experiment.
- `new_results/`: complete saved four-arm, guide-diagnostic and PertRank-Q results, plus directly readable CSV extracts. Full precision is retained. The extracts were generated by selecting fields from saved result objects, without refitting or rescoring.
- `EVIDENCE_MAP.csv`: main-figure/section links to data and replay entry points.
- `ANALYSIS_IDENTITIES.csv`: analysis population, reference use and inference scope.

The manuscript table exports are generated from the final manuscript and SI during the paper build; their table numbers belong to this release. The `figures/` directory contains numerical source inputs, not manuscript images.

## Quantities that must remain distinct

A19-R evaluates all 52/59/63 candidates at K=10. PertRank-Q evaluates source-specific, held-target subpools of 26/26, 32/27 and 35/28 candidates, each at K=10. Their absolute precisions are not directly comparable. Three input sources use one external knockout RNA experiment.

`conditional95_low/high` are paired query-block intervals conditional on the given inputs, reference and selected models. They do not measure uncertainty over the whole development search. The four-arm reference-draw ranges are sensitivity summaries, not biological-replicate confidence intervals. The D2 original-readout geometry lower bound of approximately 4.34e-19 is numerical zero.

Guide cross-products and sign counts are descriptive; 20 partitions reuse the retained cells. The 42 eligible early cross-guide zero-weight entries are distinct from the four original zero anchors inherited by PertRank-Q.
