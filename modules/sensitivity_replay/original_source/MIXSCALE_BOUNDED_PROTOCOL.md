# Official Mixscale, one bounded D3 comparison

Status: development comparison on the opened D3 responsive 20-cell task; not a new held-out confirmation. No choice below uses a new reference score. PertRank k=5,beta=.9 and all frozen task definitions stay unchanged.

Implementation: author repository satijalab/Mixscale, commit `3d3a2cd12e62382df01c056536d967534b2de3a9`, package 0.3.0. Execute the official R functions; do not translate them to a simplified replacement. Use Seurat 5 compatibility with assay version v3 as in the author's tutorial. Record exact installed package versions. If the private Seurat helpers required by the pinned code are absent, stop and report the compatibility blocker.

Input: D3's exact 1200 targets×20 input cells plus the original 2000 input NTCs, in the existing B3 cell_index order. Read raw counts on the full source gene axis; controls, total-count normalisation inputs, barcodes and ENSG identities must match existing read checks. All score learning and fitting use only these cells. The deep state appears only in the final common evaluator. The original responsive query panel is supplied unchanged; its previous larger-pool selection remains a limitation shared with the other methods.

Pipeline settings, selected from the official tutorial/defaults: NormalizeData(LogNormalize, scale.factor=10000); FindVariableFeatures(vst,nfeatures=2000); ScaleData; RunPCA(npcs=50,seed.use=20261005); CalcPerturbSig(assay=RNA,slot=data,reduction=pca,ndims=40,num.neighbors=20,new.assay.name=PRTB,split.by=NULL); RunMixscale(assay=PRTB,slot=scale.data,min.de.genes=5,min.cells=5,logfc.threshold=.2,max.de.genes=100,pval.cutoff=.05,fine.mode=FALSE,harmonize=FALSE,seed=10282021). Preserve the author's leave-one-gene-out signature logic.

Final regression: official Run_wmvRegDE(assay=RNA,slot=counts,logfc.threshold=0,min.pct=.1,min.cells.group=10,total_ct_labels=nCount_RNA,split.by=NULL). The filtering and native 0/1 fallback for targets without usable Mixscale scores are retained. Fit target by target to checkpoint output and report runtime; do not use a reduced candidate pool in evaluation. Report which targets received weighted vs native-standard fits.

Single ranking output: `beta_weight`, in each supplied query's signed direction. This is the native regression-coefficient comparison, not a claim that its native DE-test calibration or all possible Mixscale outputs have been evaluated. No switch to p-values/logFC after seeing the result. Queries absent from the regression output due to the specified native expression filter receive constant score zero; eligibility coverage is reported. A runtime error, nonfinite returned coefficient, malformed output, failed identity check or unsupported package API is a blocker—not evidence that Mixscale loses. Do not silently turn failed fits into zeros.

Evaluation: exactly the original D3 candidate pool, responsive queries, own-target exclusion, up/down directions, independent boundary-tie expectation and deep 100-cell reference. Compare PertRank−Mixscale, Euclidean−Mixscale and Mixscale−Unweighted. Report the original query-block conditional interval with its limitations; this single development test does not broaden old confirmatory claims.

Smoke: run the full official path on the two targets with highest stored input-only Euclidean weights plus the same 2000 NTCs. This deliberately tests a substantial signature and has no inferential role; no scoring against truth. Estimate runtime and peak-memory feasibility before the full target set. Do not change thresholds if the smoke lacks scores or errors. Feature, parameter and implementation hashes are recorded before running either the smoke or full analysis. Sealed D4, HEK293T and stimulated contexts are untouched.

Primary sources: https://github.com/satijalab/Mixscale/tree/3d3a2cd12e62382df01c056536d967534b2de3a9 and https://satijalab.github.io/Mixscale/ . These document cell-signature learning, leave-one-out scoring, the weighted Gamma-Poisson regression and native fallback. Tutorial retrieval was 5 October 2026.

Computational execution fixed before real fitting: serial two-target smoke; full regression uses at most four native-R fork workers on the single full-data fitted signature object. The official per-target call is unchanged; each regression call starts with seed 20261005+cohort index. All 1200 successful outputs are required. Record RSS/object sizes after each major stage and preserve the fitted object for exact checkpoint continuation. If memory or runtime prevents completion, report incomplete; do not reduce features, LOO or candidate pool.
