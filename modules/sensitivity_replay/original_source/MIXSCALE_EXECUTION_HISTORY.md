# Official Mixscale execution history

All runs use author commit 3d3a2cd12e62382df01c056536d967534b2de3a9 and the unchanged native scientific functions/parameters. This log distinguishes execution failures from scientific results. No deep-reference comparison has been evaluated at the time this note is first written.

- The real two-target smoke completed both native signature fitting and regression.
- Two initial full-object runs exceeded the predeclared execution memory guard (below the 8 GiB container limit). Neither produced a complete scientific comparison. The global native preprocessing was then saved without changing its values.
- Compact storage was independently audited. Four fixed input-selected targets, including one actual native standard fallback and three weighted targets, match the original native multi-target call exactly in all score/LOO and DE values. The complete 1,200-block disk roundtrip is exact. The four-target export identity report was overwritten by the full export report; the native four-target equivalence report and its results remain. An older review SHA for that export report therefore does not name the current full export report.
- The first full exporter unnecessarily reconstructed all 2,000 NTC cells for every target. It was interrupted and replaced by an execution-only export that checks the shared NTC once and every target block independently, retaining the already-passed full-object gate.
- Four-worker fitting hit the memory guard before any target completed. Two-worker fitting then completed the first 20 targets (mean 40.8 s/target, of which 6.9 s signature and 33.9 s regression). Its trailing script parsing failed because I edited the same R file during execution to insert explicit garbage collection; R was continuing to read the file. The fitting function had already been loaded, and all 20 native fits and their CSV/status checkpoints completed before that footer error. The original file is preserved as run_compact_mixscale_before_gc.R, and current static parsing passes. No numerical result was changed or reselected. Subsequent live scripts must not be edited.
- Two memory-only garbage-collection experiments used R_GC_MEM_GROW=0 plus gc() after object construction and native signature fitting: four workers and then three workers. Both hit the unchanged memory guard before any additional target completed. These are not Mixscale method failures.
- The complete 1,200-target continuation uses two workers, default R_GC_MEM_GROW, and the two explicit gc() calls. This supersedes any wording in the GC trial freeze suggesting that all later runs necessarily set R_GC_MEM_GROW=0. Per-target seeds, full 18,130-feature axes, original cells and every LOO calculation remain unchanged. Existing valid native fits are reused.

Scientific outputs are complete only when all 1,200 target CSVs/status records pass checks and RUN_COMPLETE.json exists; a partial run is not eligible for scoring. Native expression-filtered query entries are handled by the frozen evaluator, while fit errors or nonfinite returned coefficients never become zeros.

- At 42 completed targets, the two-worker chain was paused at a valid checkpoint for a predeclared execution-only slot-release gate. All four fixed targets' complete native DE outputs were identical after removing PRTB and RNA scale.data, releasing 65–66 MB per target. Native scores, all LOO values, RNA counts/data and metadata were retained.
- A new immutable file, run_compact_mixscale_de_released.R, contains that gated adapter. Its three-worker test still reached the memory guard with no new completed targets. The final full continuation therefore uses two workers and default R memory growth. No more parallelism variants are being tried. The original 42 fits are reused unchanged; all subsequent fits are the same native calculations with two unused slots released. The active script is not edited while running.
- Four sampled native DE profiles show that most time is in dispersion optimization and coefficient fitting, not large matrix multiplication. They do not justify another BLAS-thread experiment. Source data, native full-gene empirical-Bayes dispersion calculation, 1,200 candidates, and all LOO fits remain intact despite the long execution time.
