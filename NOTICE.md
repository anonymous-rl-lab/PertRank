# Component provenance and rights

This package contains PertRank scientific code, retained experimental inputs and manuscript source tables. Independent dataset accessions, method citations and third-party component notices are retained. Project-owned registration identifiers use neutral analysis-role aliases for anonymous review.

The installable software has its own LICENSE. That notice does not automatically extend to external datasets, third-party programs or manuscript source tables. FR-Perturb, GPerturb, SCITO and other included upstream components retain their own notices. Components that cannot be redistributed under a verified license are represented by pinned provenance or retrieval instructions.

Reproduction uses the fixed inputs, dependency versions and seeds documented for each workflow. Source-table rendering, numerical recomputation, checkpoint inference and native fitting have distinct entry points and scopes, as described in the coverage documentation.
