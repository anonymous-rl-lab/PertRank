# Component provenance and rights

This is an integration of the user's PertRank research archives and paper package. Scientific source, dataset attribution, public accession identifiers and component-specific notices are retained. Project-owned registration identifiers are replaced by documented role aliases for anonymous review; original records and the mapping are retained separately. Current payload manifests and the migration inventory identify the maintained release.

The installable software has its own LICENSE. That licence is not automatically extended to external datasets, archived third-party programs or the manuscript source tables. FR-Perturb, GPerturb, SCITO and other included upstream components retain their own notices. Where upstream source is not redistributable under a verified licence, the archive supplies its pinned provenance or retrieval recipe instead of assigning a new licence.

No licence change or public deposition is performed as part of this integration. For public repository use, retain the component notices and original dataset citations. Exact scientific reproduction must use the stated fixed input roles, versions and seeds; the review-oriented figures and archived summaries alone do not substitute for the computational input level described in the coverage table.
